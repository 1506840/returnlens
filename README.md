# ResearchLens：基于 Qwen 的科研假设生成系统

> 天猫 AI 黑客松 · 阿里云特别赛题「基于 Qwen 大模型的科研提效：认知增强与研发范式革新」

## 一句话定位

ResearchLens 是一套**科研认知增强流水线**：把研究者需要数天完成的「读文献 → 找空白 → 提假设 → 排优先级」，压缩为分钟级的自动化闭环。

## 核心范式

```
文献挖掘（归因）→ 假设生成与可行性论证（决策）→ 研究进展追踪（复盘）→ 科学图表理解（多模态）
```

## 设计理念

| 维度 | 说明 |
|---|---|
| **认知增强** | 不替代研究者判断，而是加速"证据整理与初步推断"，把人的时间留给创造性决策 |
| **证据可追溯** | 每个假设、每条结论都附带文献来源与置信度，低置信自动标记"待补实验" |
| **范式革新** | 从"线性阅读 + 手动归纳"升级为"长上下文并行对比 + 结构化空白发现 + 自动可行性评分" |
| **零漂移** | 支持增量新增论文/假设，不重算已有结论，保证研究记录稳定可复现 |

## 技术架构

### 四层模块

| 科研模块 | 源模块（电商归因系统） | 复用率 | 核心改造 |
|---|---|---|---|
| **文献挖掘** `literature_mining.py` | `attribution.py` | ~70% | 五元组抽取 + 研究空白发现 + quote 命中校验 |
| **假设生成** `hypothesis_generator.py` | `decision.py` | ~55% | 多维可行性评分 + 门控拦截 + 敏感性分析 |
| **进展追踪** `research_tracker.py` | `review.py` | ~80% | 纯本地聚合 + 按空白类型分支给建议 |
| **图表理解** `chart_understanding.py` | `vision.py` | ~85% | 科学图表数值提取 + 图文矛盾检测 |

### 关键设计

**1. 封闭枚举 + 可机器校验的证据约束**

所有分类（空白类型、假设类型、资源标签等）均为封闭枚举，模型输出必须严格匹配。每条证据引用（quote）必须能在论文全文中字符串命中，命中率可当场验证。

**2. 门控拦截的可解释性**

假设生成不是"有求必应"，而是通过 5 道门控规则过滤：
- 违反已知物理/数学定律（violates_physical）
- 无法导出可验证的预测（no_testable_prediction）
- 已被现有文献充分回答（already_answered）
- 所需数据不可获取（data_unavailable）
- 预估工时超出预算（effort_exceeds_budget）

门控由两层构成：**结构校验**（陈述/方法/证据/rationale 长度、预算、子分范围）+ **语义门控**（LLM 在生成时对上述 5 条规则逐条返回布尔判断 `gate_flags`，`hypothesis_generator.gate()` 聚合二者，任一违反即拦截）。规则定义唯一真源在 `taxonomy.GATE_RULES`，prompt 动态注入，避免文档与代码脱节。每条被拦截的假设都附带具体原因。

**3. 多维可行性评分**

假设不再用单一指标衡量，而是从 4 个维度打分：
- **新颖性**（30%）：在已有文献中是否未被覆盖
- **可行性**（30%）：在给定资源下能否被实验验证
- **影响力**（25%）：若成立，对领域的推动程度
- **证据强度**（15%）：当前文献证据的支撑力度

每个子分必须附带一条证据说明打分理由。

**4. 零漂移增量机制**

新增论文时，冻结已有结果，只计算新增部分，保证旧结论 MD5 不变。研究记录稳定可复现。

## 技术选型

| 组件 | 方案 | 理由 |
|---|---|---|
| 基座模型 | Qwen-Max / Qwen-Plus（百炼 API） | 长上下文 + 智能体能力最强 |
| 多模态 | Qwen-VL-Max | 科学图表理解能力强 |
| 界面 | Streamlit | 快速原型 + 无 pandas 依赖（DLL 限制） |
| 数据 | JSONL 缓存 | 零漂移 + 断网可演示 |

## 种子论文

系统基于 4 篇真实论文构建（子领域：多模态大模型视觉推理）：

| # | arXiv ID | 标题 | 角色 | 引用 |
|---|---|---|---|---|
| 1 | 2310.03744 | LLaVA-1.5 | 📚 经典 | ~6500 |
| 2 | 2310.11441 | Set-of-Mark Prompting | 🆕 近作 | ~864 |
| 3 | 2409.02813 | MMMU-Pro | 🆕 近作 | ~506 |
| 4 | 2403.16999 | Visual CoT | 🆕 近作 | ~458 |

论文之间形成闭环交叉引用，系统可自动发现跨论文研究空白。

## 快速启动

```bash
# 1. 文献挖掘（读取论文 → 抽取五元组 + 发现空白）
python literature_mining.py

# 2. 假设生成（基于空白 → 生成假设 + 可行性评分）
python hypothesis_generator.py

# 3. 进展追踪（聚合所有结果 → 研究全景报告）
python research_tracker.py

# 4. 启动界面
streamlit run app.py

# 5. 增量挖掘（新增论文后，零漂移）
python run_incremental.py llava15
python research_tracker.py
```

## 答辩亮点

### 亮点 1：反幻觉硬指标

每条研究空白的 quote 必须能在论文全文中字符串命中。当场运行校验脚本，报告 N/M 命中率。这是可机器验证的反幻觉指标，全场独一份。

### 亮点 2：门控拦截演示

故意提一条违反物理常识的假设（如"用单卡 GPU 训练 1T 参数模型"），系统会拦截并给出具体原因。评委看到系统"说不"比看到系统"说 yes"更有说服力。

### 亮点 3：零漂移工程可信度

新增论文前后，旧结果 MD5 完全一致。一句话说明可回归、可审计。

### 亮点 4：判别力故事

两条来自同一子领域的研究线索：
- **线索 A**：文献明确报告了该场景的结果、方法也覆盖 → 判为"已被充分研究"，不生成新假设
- **线索 B**：文献声明覆盖但该场景缺基线、图表数据与正文结论存在偏差 → 判为"真实研究空白"，生成可验证假设

同一套模型，输入证据不同，一个收敛、一个发散——系统不是在猜方向，是在读证据。

## 诚实划界

ResearchLens 是**缩小搜索空间的工具**，不是**替代科学家的自动发现系统**。所有生成的假设都未经实验验证，最终需要研究者判断。系统的价值在于：把 4 天的文献调研压缩到 8 分钟，让研究者把时间花在创造性决策上。
